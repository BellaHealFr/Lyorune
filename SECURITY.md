# Sécurité

## Versions suivies

Seule la dernière version publiée de Lyorune reçoit des corrections.

## Où télécharger Lyorune

Il n'y a que quatre sources officielles, mises à jour en même temps et publiées par BellaDroode : la page du projet sur GitHub (https://github.com/BellaHealFr/Lyorune/releases/latest), la page CurseForge « Lyorune Healing » (https://www.curseforge.com/wow/addons/lyorune-healing), la page Wago (https://addons.wago.io/addons/lyorune) et la page WoWInterface (https://www.wowinterface.com/downloads/info27323-Lyorune.html). Toute autre adresse, ou un fichier envoyé par un joueur, peut contenir une copie modifiée. Lyorune ne vous demandera jamais de télécharger quoi que ce soit ailleurs.

## Ce que fait Lyorune avec vos données

- Lyorune n'envoie rien sur internet : un addon de World of Warcraft n'en a pas la possibilité.
- Ses réglages et son journal d'erreurs restent dans le fichier `WTF\Account\<COMPTE>\SavedVariables\Lyorune.lua` de votre ordinateur.
- Entre joueurs qui utilisent Lyorune, seuls circulent le numéro de version et les configurations que vous choisissez d'envoyer. Une configuration reçue n'est jamais appliquée sans votre accord, et chaque valeur est contrôlée à l'import. Elle n'arrive que d'un membre de votre groupe, de votre guilde ou de votre liste d'amis. Vos macros et les phrases de vos annonces ne sont jamais partagées.
- Le rapport de bug (`/lyorune bug`) remplace le nom de votre personnage, de votre royaume et des membres de votre groupe avant que vous le copiiez.

## Signaler une faille

Si vous pensez qu'un code de configuration, un message entre joueurs ou toute autre entrée peut être détourné pour nuire à un joueur, ne l'exposez pas publiquement. Utilisez le signalement privé de GitHub : onglet « Security » du dépôt, puis « Report a vulnerability ».

Vous recevrez une réponse dès que possible, et la correction sera créditée à votre nom si vous le souhaitez.
