# Code de conduite

Lyorune est un projet fait par passion, pour des joueurs. Dans les demandes et les discussions de ce dépôt :

- Restez courtois, y compris en cas de désaccord.
- Critiquez les idées et le code, jamais les personnes.
- Pas d'insultes, de harcèlement ni de propos discriminatoires.
- Restez dans le sujet : Lyorune et le soin dans World of Warcraft: Forever.

Les messages qui ne respectent pas ces règles peuvent être masqués ou supprimés, et leur auteur écarté du dépôt.

Pour signaler un comportement, contactez BellaDroode par le signalement privé de GitHub.
